# SARFAROSH — WEBSITE ARCHITECTURE & UX FLOW
## Master Information Architecture for the Sarfarosh Event Management Website

**Document purpose:** This document defines the complete website structure, page hierarchy, navigation flow, content depth, and user journey for the future Sarfarosh website.

**Design principle:** The website should feel like a premium event-management, experience, production, and entertainment company — not a simple portfolio or performing-arts website.

**Primary objective:** Make Sarfarosh look established, credible, capable of large-scale execution, and easy to hire while allowing users to explore deeply if they want to know everything.

---

# 01. WEBSITE CORE IDEA

The website should communicate one simple progression:

**WHO WE ARE → WHAT WE DO → WHAT WE HAVE DONE → HOW WE WORK → WHY TRUST US → WORK WITH US**

The visitor should be able to understand Sarfarosh quickly, but the website should contain enough depth that a serious client, government organization, corporate brand, partner, journalist, artist, or potential collaborator can explore the company in detail.

The website should therefore have:

- A simple top-level navigation
- Deep internal pages
- Strong case studies
- Dedicated service pages
- Dedicated event categories
- Founder and company story
- Government/public-sector section
- Client/partner proof
- Media and documentation
- Clear enquiry journey

# 33. INFORMATION DEPTH

The website should work at three levels.

## LEVEL 1 — QUICK UNDERSTANDING

For someone who spends 30 seconds.

They should understand:

**Sarfarosh = Event Management + Experiences + Production + Entertainment**

## LEVEL 2 — CLIENT RESEARCH

For someone spending 5–10 minutes.

They should understand:

- Services
- Events
- Clients
- Capabilities
- Founder
- Process
- Proof

## LEVEL 3 — DEEP RESEARCH

For someone who wants everything.

They should be able to explore:

- Complete story
- Individual projects
- Government work
- Competition history
- Press
- Achievements
- Team
- Experience philosophy
- Production capabilities
- Case studies
- Testimonials
- Insights

This is what makes the website feel **large and established** without overwhelming the homepage.

# 34. VISUAL HIERARCHY

The website should use a consistent visual hierarchy.

## Tier 1

Full-screen cinematic imagery/video.

Detailed metadata.

---

# 35. DESIGN LANGUAGE

Recommended direction:

**Premium + Cinematic + Editorial + Modern**

Avoid:

- Generic event-agency templates
- Excessive gradients
- Too many colors
- Excessive cards
- Stock photography
- Over-animation
- Cheap-looking effects
- Excessive rounded UI
- Huge walls of text

Use:

- Strong typography
- Large imagery
- Full-width media
- Black / off-white / charcoal base
- One controlled accent
- Smooth transitions
- Intentional motion
- Strong spacing
- Editorial layouts

---

# 36. MOTION PRINCIPLE

Animation should communicate:

**Scale + Energy + Premium Execution**

Use:

- Scroll reveals
- Image transitions
- Text movement
- Video transitions
- Horizontal project movement
- Subtle hover states

Avoid:

- Constant bouncing
- Excessive parallax
- Slow loading animations
- Decorative effects with no purpose

The site should feel alive because of the content, not because every element is animated.

---

# 37. CONTENT PRINCIPLE

Every page should answer:

### WHAT?

What is this?

### WHY?

Why does it matter?

### PROOF?

This prevents the website from becoming a collection of disconnected sections.

# 49. FINAL DESIGN PHILOSOPHY

**Simple at the surface. Deep underneath.**

A first-time visitor should understand Sarfarosh within seconds.

A serious client should be able to spend 15–30 minutes exploring the organization and still discover new information.

The website should therefore behave less like a brochure and more like a **digital company ecosystem**.
